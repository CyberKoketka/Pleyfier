БЫСТРЫЙ ЗАПУСК
Нужна установленная Java 17 или новее. Для пересборки нужен JDK, для готового JAR достаточно среды выполнения Java.
Консоль: java -jar PlayfairCipher.jar
Windows: run-console.bat или run-gui.bat.
macOS: run-console.command или run-gui.command. Если нет права запуска:
  chmod +x run-console.command run-gui.command
  ./run-gui.command
Linux x64: sh run-gui.command
В графическом режиме Java должна соответствовать архитектуре ОС. Комплект JavaFX содержит Windows x64, Linux x64, macOS Intel x64 и Apple Silicon arm64. Linux arm64 в комплект не включён.

ПОРЯДОК РАБОТЫ
Выберите шифрование или расшифрование, существующий файл, ключ от 3 символов и НОВЫЙ путь для результата. Существующие файлы не перезаписываются. Ключ чувствителен к регистру и пробелам. Запомните точную фразу. Пустые файлы поддерживаются. Максимальный размер исходных данных - 64 МиБ; при расшифровании дополнительно допускаются 20 байтов заголовка.
В консоли слово «отмена» возвращает в меню. Команда 3 завершает работу. В GUI сначала выберите файл, введите ключ и нажмите нужную кнопку, затем укажите новый путь результата.

КОМПЛЕКТ
Report.docx - исправленный(мною, Кокориным А.А.) отчёт, включая исходный код приложения.
PlayfairCipher.jar - готовая программа с Log4j внутри.
project/ - полный Gradle-проект с Wrapper, исходниками, тестами и библиотеками.
javadoc/index.html - документация всех методов, включая private.
test-report/index.html - результаты 37 JUnit-тестов.
evidence/ - исходные журналы проверок, XML JUnit и иллюстрации.
examples/ - тестовые файлы и результаты восстановления. Ключ примеров: secret.
CHANGES.txt - перечень изменений и особенности формата.
CRITERIA.txt - соответствие пунктам шкалы преподавателя.
THIRD_PARTY.txt - сведения о внешних компонентах и исходном проекте.

СБОРКА
Из каталога project:
  macOS/Linux: ./gradlew clean test jar javadoc
  Windows: gradlew.bat clean test jar javadoc
Проверено на JDK 17.0.17 и Gradle 8.14.3. При первом вызове Wrapper скачает Gradle; библиотеки уже включены в project/libs. Для повторной сборки без сети после загрузки Gradle добавьте --offline.
Результат сборки: project/build/libs/PlayfairCipher.jar.
Для обновления готовой программы в корне, пожалуйста, скопируйте туда новый JAR после сборки.

ФОРМАТ И ОГРАНИЧЕНИЯ
Проект использует контейнер PFC2 с длиной и CRC32 матрицы и данных. Это учебный шифр, не средство защиты конфиденциальных данных. CRC32 при этом ни в коем случае не является MAC или электронной подписью.
